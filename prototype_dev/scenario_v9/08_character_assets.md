# Перечень изображений персонажей — редакция 9

Пять эмоций, пять поз и два кадрирования дают 300 вариантов полной матрицы для шести персонажей. Полная матрица не заказывается автоматически: ниже перечислен рабочий набор сочетаний, поставленных в написанных сценах. Предметные кадры со скрытыми спрайтами не добавляют изображений. Набор можно пересмотреть при режиссёрской проверке, без изменения числа эмоций.

**Рабочий итог: 80 исходных рисунков и 104 игровых экспортов.** Один исходник — персонаж в конкретной позе с конкретной эмоцией, нарисованный целиком. Из него получают только необходимые в сценах кадрирования. Если нужны оба, это один исходник и два экспорта, а не две независимые генерации. Файлы пока не созданы.

Исходники хранить вне сдаваемого игрового каталога в source_art. В assets включать только игровые PNG с прозрачностью. У всех экспортов одной позы сохранять масштаб тела и опорную точку. Поясной кроп должен включать необходимые руки и блокнот; если кроп их отрезает, править композицию исходника и повторно проверять оба экспорта. Нельзя обещать хороший кроп только по арифметике. Полный рост проверять на вертикальном экране отдельно от поясного.

Файл character_assets.json содержит точные относительные пути, ключи ресурсов и сцены использования. Запись full означает полный рост, waist — по пояс. Штатный show может использовать составной ключ состояния, например i03_sad_waist: это имя ресурса, а не шестая эмоция. Изменений системных файлов движка не требуется. Фактический синтаксис регистрации проверить на выбранной стабильной версии при реализации.
